# 片悟 · Pianwu 演示

## 打开方式

1. 先完整解压 `pianwu-demo.zip`。
2. 进入解压后的 `pianwu-demo` 文件夹，用浏览器打开 `index.html`。
3. 请把所有文件放在同一个文件夹中，架构图和全文稿跳转需要相对路径。

本演示可离线查看，无需安装 Python 或其他依赖。

| 文件 | 内容 |
|---|---|
| `index.html` | 主页面：知识学习 / 怎么复刻 / 对照看 |
| `index.svg` | 可独立打开和编辑的内容架构图 |
| `index_table.md` | 纯表格版，包含学习与制作内容 |
| `transcript_full.html` | 带章节、时间码和搜索的演示文稿 |

可以先切换「对照看」，再点击 00:08 等时间码；制作线提供镜头清单、口播稿与可勾选执行清单。

## 数据说明

「60 秒咖啡短片：从看懂到会拍」为片悟 · Pianwu 原创合成演示，非真实视频分析或转写。全部台词、镜头、时间码与时长均为示意；本包没有视频、照片、录屏、配乐或观看效果数据。拍摄建议是练习起点，按自己的场地、设备和素材调整。
