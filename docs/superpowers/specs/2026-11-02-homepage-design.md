# 首页与新手体验改版

## 目标

让首次访问者看懂价值、看到真实界面、获得第一次成功，再选择安装与 Star。用户同时要求竞品调研和更利于传播的名字。

## 方案取舍

1. 通用视频总结：容易解释，但与成熟笔记工具直接重叠。
2. 全能下载与转写工具：能展示平台广度，但平台风控与依赖成为首体验。
3. 学懂内容 + 拆出拍法：突出已有逐章节配对的学习/制作/对照视图；采用此方向。

展示名采用建议方案「片悟 · Pianwu」，标语「学懂内容，拆出拍法。」。这是本次编辑选择；仓库地址与技能调用名仍使用现有 video-digest-skill / video-digest，保持已发布链接有效。名称的公开检索结果不代表商标或域名可用结论。

## 改动范围

- 重写中英文 README，先展示效果与开始入口，再解释能力、适用范围、限制。
- 重写安装说明，区分免安装体验、Agent 宿主安装、手动 CLI 处理。
- 新增明确标注为原创虚构的完整演示，含 outline、时间码文稿、现有生成器产出的四个文件和演示 ZIP。
- 使用真实渲染截图展示界面；精确排版的 SVG 封面用于品牌识别。
- 同步 llms.txt 与 SKILL.md 中已过时的入口、输出条件和隐私说明；提供根目录含 SKILL.md 的导入包。
- 保存有来源和检索日期的竞品、命名及推广建议。

## 约束

- 不把 all 命令描述为自动完成内容创作；Agent 需要读素材、写 outline.json。
- 仅传入文稿才有第四件全文稿；页面分享需要携带 SVG、文稿和引用图片。
- 本地媒体处理不等于宿主模型全程本地推理。
- 不宣传不存在的 --device cuda 参数，不承诺固定安装时长或转写速度。
- 图文、平台解析、客户端兼容均明确验证范围；不把离线夹具通过当成线上测试通过。
- 本次只改文档与演示数据，复用现有渲染器。

## 验收

在 Python 标准库环境重建完整示例；检查四个产物与本地引用；浏览器检查学习/制作/对照切换、章节互跳、全文搜索、勾选记忆和桌面/手机显示；检查中英文首页链接与命令；由独立审阅者核对宣传与代码。
